# 🎨 Pollinations Image Generator

A simple web app that generates images using the [Pollinations AI](https://pollinations.ai) API.

## Features
- Text-to-image generation
- Multiple models: flux, flux-realism, flux-anime, flux-3d, turbo
- Custom resolution (512 to 1280px)
- Download generated images

## Usage

Open `index.html` in your browser, enter a prompt and click **Générer**.

Built with [Pollinations.ai](https://pollinations.ai) — Free Open-Source AI Image Generation API.
